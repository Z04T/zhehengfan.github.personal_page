# Personal Webpage

This is a static academic-style homepage: profile, education, research projects, skills, written works/posters, and contact links.

## Full Control

Most content is controlled from `content.js`.

Edit this file when you want to change:

- Your name, initials, browser title, and site description
- Hero text and buttons
- About paragraphs
- Profile photo in the Zheheng Fan section
- Education entries
- Focus cards
- Research project detail pages
- Written works and posters
- Contact links

The page reads `content.js` automatically when `index.html` opens.

## Edit These Files

- `content.js`: change your content and links.
- `index.html`: change the structure only if you want to add, remove, or rearrange sections.
- `project-*.html`: individual research project pages, populated from `content.js`.
- `research-projects.html`: overview research project page, populated from `content.js`.
- `assets/immunology-hero.svg`: replace with a portrait, lab/work image, or another hero image if you want a more personal first impression.
- `assets/profile-placeholder.svg`: replace or bypass this with your real profile photo path in `content.js`.
- `styles.css`: adjust colors in the `:root` block if you want a different visual identity.

## Preview

Open `index.html` directly in a browser. No build step or development server is required.
